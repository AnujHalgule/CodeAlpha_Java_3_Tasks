# Hotel Reservation System

A Java console-based application for managing hotel room reservations.

## Features

- View available rooms
- Book a hotel room
- Cancel a reservation
- View all bookings
- Search booking information
- Exit the application

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Eclipse IDE
- Console-based Application

## Project Structure

- `Room.java` - Represents hotel room details.
- `Booking.java` - Represents reservation and customer details.
- `HotelReservation.java` - Main application containing the reservation system.

## How to Run

1. Open the project in Eclipse IDE.
2. Make sure all Java files are in the `hotel_reservation` package.
3. Run `HotelReservation.java`.
4. Follow the instructions displayed in the console.
